# Tenant detail as a page

- `Open` now navigates to a dedicated `tenant` view instead of opening a modal dialog.
- The Tenants navigation item remains current on the tenant page.
- Breadcrumb becomes `Platform / Tenants / <tenant name>`.
- The page is read-only: profile, quota, billing, users, models, upstreams, support, usage and audit.
- Editing remains explicit through "Edit profile", "Edit quota", "Edit billing", "Add user", "Add upstream", and "Request support" dialogs.
- Back to tenants returns to the table and refreshes data.
- Status filter field widened to 250px so the value and arrow no longer collide with the result count.
