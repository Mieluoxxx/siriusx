# Lean tenant list

- Removed the DIRECTORY eyebrow and page description.
- Removed the permanently visible Create tenant form; it is now a `+ New tenant` dialog.
- Removed the duplicate table caption.
- Removed Open button; whole row opens the tenant page, with keyboard Enter/Space support.
- Removed Issuer, Devices, Device tickets and Cloud tickets from the list.
- Moved the platform token into an Access popover; it auto-opens only when no token exists.
- Notifications button hides when there are no unread notifications.
- Reset and result count appear only when a filter is active.
- Top-level breadcrumb is hidden; it returns for nested tenant pages.
