# Admin sidebar visual hierarchy

- Inline SVG icons for all navigation items, decorative and `aria-hidden`.
- Grouped navigation: Workspace, Operations, Governance.
- Environment card with current LAN endpoint.
- Bottom connection status and product version.
- Gradient sidebar surface with subtle top glow.
- Active item uses a blue gradient with a left rail and highlighted icon tile.
- Mobile popover uses dark text on the white surface and restores left-aligned icon/label rows.
